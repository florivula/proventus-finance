# Proventus Finance website

Static credibility website for Proventus Finance. The public build is the `public/` directory and has no compile step.

## Commands

- `npm install`
- `npm run dev` serves `public/` on port 4287 through Wrangler.
- `npm run check` runs the local structural verifier.
- `npm run deploy` publishes `public/` to Cloudflare Pages project `proventus-finance`.

## Visual direction

Deep financial green, warm ivory and a sharp chartreuse signal. The identity is built around a custom SVG P: ledger lines carry into a forward balance mark. Keep the site premium through typography, spacing and instrument-like motion. Do not replace it with generic finance photography, gradients or stock icons.

## Content boundaries

The only confirmed company facts are the name and these services: accounting, payroll, VAT, tax declarations and financial reporting. Do not invent accreditations, staff, offices, jurisdictions, years in business, client counts or quantified outcomes. `hello@proventusfinance.com` is provisional until the client confirms the operating contact.

## Release checklist

Run the structural check, verify desktop and mobile layouts, test keyboard navigation and reduced motion, confirm `/`, `/privacy`, a missing route, console cleanliness and security headers, then verify the exact production deployment.
